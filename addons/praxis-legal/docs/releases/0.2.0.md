# Praxis Legal 0.2.0

The first integration is MCP only. Users connect `praxis-legal` and ask Mosaic chat to call `ask_praxis`. The catalog tab shows connection and tool availability; it has no question form and does not create agents. Its only permission is `mcp:read`.

The MCP server remains a separate installation. It resolves the Praxis key from 1Password and calls the user-bound Praxis API. Catalog publication and a fresh catalog installation still require maintainer approval.
