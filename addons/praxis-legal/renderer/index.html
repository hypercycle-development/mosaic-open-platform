Praxis Legal MCP

Add Praxis as an MCP server, then ask questions in Mosaic’s AI Chat.

  1. Install the Praxis MCP server separately using the setup instructions shipped with its source.
  2. In MCP Servers, connect praxis-legal. Its tool is ask_praxis.
  3. Open AI Chat with your configured Mosaic agent. Ask: “Use ask_praxis to answer: What is the Rule 56 summary judgment standard?”

The current integration supports public-law research. Do not include client or matter facts.
